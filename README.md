# kra_toggleprop
This free script allows you to attach any 3D prop to the character’s head (or any other configurable bone) using a toggle system controlled through an inventory item. Fully compatible with VORP.

It’s ideal for masks, helmets, accessories, or any custom 3D model you want to equip on your server.

This system also integrates perfectly with all premium masks available in my shop, allowing players to equip them with a simple click directly from their inventory.

Thanks to its fully customizable configuration file, you can add unlimited props and fine-tune their position and rotation using Spooner or any tool of your choice.

Perfect for servers that want to give players a smooth and elegant way to wear masks and accessories in-game.
